# Practices — каталог проектов

Репозитории X-Keeper и SphereTele описаны в каталоге Practices (MCP-сервер `practices`): пространство → проект → репозиторий → сервис, связи «кто кого вызывает», условия доступа, практики.

- Перед работой с данными или чужим сервисом: `search` и `get_service` — там адреса, условия (VPN, авторизация), кто уже ходит туда и как. Копируй практики как есть, первая строка `# practices: …` — метка копии.
- Закончил работу в репозитории из каталога (новый вызов другого сервиса, новая база, топик, переменная окружения, снятая зависимость) — обнови карточку: `add_link` для новых связей, `add_note` для подводных камней, `describe_field` для полей, `update_practice` для новых или исправленных практик. Правки остаются в `pending`, пользователь принимает их сам.
- Секреты в каталог не пишутся: только имена переменных.

Настройка Practices новому человеку: `practicesctl setup status`, `setup roots`, `space clone <url>`, `setup agents` — спросите пути и URL у пользователя.
