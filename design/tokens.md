# Practices Mockup — токены дизайна

Исходники экранов Claude Design (канва https://claude.ai/artifact/6xPJyEnMAesK1ccbb8Ue5R, 7 ноября 2026).
Каждый `*.dc.html` — самодостаточная страница: разметка экрана с инлайн-стилями плюс блок
`<script type="text/x-dc">` с данными примера. `Sidebar.dc.html` — общий компонент, остальные экраны
подключают его через `<dc-import name="Sidebar" selected="…" scroll="…">`. `canvas.json` — раскладка
артбордов на канве. Все значения ниже — то, что реально используется в файлах; тема одна, тёмная
(macOS dark). Значения для SwiftUI — ориентир, не спецификация: в приложении берутся системные
`Color`/`Font`, где они есть.

## Правила

- Все id, пути, команды, ключи и версии — mono; человеческие названия — ui.
- Цвет несёт смысл только одним способом: вид сервиса, зона проекта или состояние (ok/warn/error). Не смешивать.
- Ключи показываются именами, значения — никогда (`задан` / `не задан`).
- Хлебные крошки в тулбаре: `пространство / проект / id`, каждая часть — ссылка, проект — цветом зоны.
- Статус-строка снизу: путь к файлу карточки, состояние git, подсказка `⌘K — перейти`.
