# Карта по вариантам A/B/E и поле `role:` — план

Начат 8 ноября 2026. Образец — HTML-прототип с настоящими данными, одобренный пользователем
(`mapdesign/tmpl.html`, снимки a, b, b_1.4, e, e_hyper-imu). Карта в окне повторяет его раскладки и
поведение; основа — решения 33–35 пласта `catalog-rebuild` и роли из его `STRUCTURE.md` §2.

Главная жалоба, которую закрывает пласт: «нельзя приблизить». Вторая — уровень проекта: один
вертикальный пучок справа, обрезанные чипы, карточки разной высоты, бесконечная колонка воркеров.

## Шаги

- [x] 1. Папка пласта: PLAN, DECISIONS, LOG; строка в `work/README.md`.
- [x] 2. `role:` у сервиса — ядро (пишется только заданное), вывод роли для карты, CLI
      `practicesctl service role <id> <role>` (без коммита — в pending), поле в MCP `get_service`; тесты.
- [x] 3. Масштаб и сдвиг для всех уровней: щипок/колесо вокруг курсора 0.4×–4×, перетаскивание,
      двойной клик — вписать, наведение гасит остальное, клик закрепляет и открывает боковую панель.
- [x] 4. Уровень проекта — вариант E: ровная сетка 8 pt, однострочные карточки, колонки
      «Вызывают из других проектов → Фронты → API → Воркеры → Данные и шина → Внешние и другие
      проекты», разбиение API/Воркеры при > 5, перенос в подколонки по 14 строк, порты по карточке,
      у каждой связи своя полоса, углы 6 pt, цвет по via, стрелки 6 pt; без цветных рамок колонок;
      вписывается целиком (не меньше 0.5×), кнопка «1:1», метки соседей за краем.
- [x] 5. Уровень пространства — вариант B с переключателем «Рамки / Поток»: рамки проектов со
      строками сервисов, < 0.8× пучки с числами, ≥ 0.8× связи сервис→сервис по коридорам; «Поток» —
      вариант A, колонки по ролям, «Обработка» разбита на подколонки.
- [x] 6. Уровень сервиса — A по нити: выбранный сервис, его цепочка вверх слева и вниз справа
      (транзитивно, до N переходов, по умолчанию 3), прямые линии, остальное скрыто.
- [x] 7. Роли в каталоге: `role:` в `service.yaml` каждого сервиса spheretele и x-keeper по правилам
      вывода, без коммита (пользователь принимает в окне); сомнительные — списком в LOG.
- [x] 8. Снимок карты в README (демо из трёх проектов в `~/Demo`, удалено после).
- [x] 9. Второй проход после просмотра: роли переписаны строкой, нить по данным, брокер на уровне
      проекта одной линией, подпроекты в «Рамках», снимок README (решения 16–18).
- [x] 10. Третий проход: нить читаемая (1 шаг, компактные колонки, «данные»/«вызовы», подписи топиков
